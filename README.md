## Projeto
Visual Novel RPG em HTML/JS/CSS puro, sem frameworks.
Tema: apocalipse com insetos gigantes.

## Convenções
- JavaScript vanilla (sem React, Vue, etc.)
- Todo roteiro fica em arquivos JSON dentro de /story/
- Comentar o código em português

## Comandos
- Abrir index.html no navegador para testar
- Não usar bibliotecas externas sem perguntar primeiro

## Prioridades
- Legibilidade do código acima de tudo (dev é iniciante)
- Cada cena deve ter: background, personagem, texto, escolhas
